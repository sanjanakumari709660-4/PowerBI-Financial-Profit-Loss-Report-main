# Financial Profit & Loss Analysis Dashboard (Power BI)

## 📊 Project Description
This project is a Financial Profit & Loss Analysis Dashboard developed using Microsoft Power BI.
The dashboard provides a clear and interactive view of an organization’s financial performance,
including profit, loss, revenue, and expenses over different time periods.

It helps stakeholders understand financial trends and make data-driven decisions.

---

## 🎯 Objectives
- Analyze overall Profit and Loss
- Compare Revenue vs Expenses
- Identify financial trends over time
- Support better financial decision making

---

## 🛠 Tools & Technologies Used
- Microsoft Power BI
- Microsoft Excel (Data Source)
- Data Cleaning & Data Modeling
- DAX (Basic Measures)

## 📌 Key Features & Insights
- Total Profit & Loss overview
- Revenue and Expense comparison
- Time-based financial analysis (Monthly / Yearly)
- Interactive visuals and filters
- Clean and user-friendly dashboard design

## 🖥 How to Use This Project
1. Download the `.pbix` file from this repository
2. Open it using Microsoft Power BI Desktop
3. Explore the dashboard using filters and visuals
